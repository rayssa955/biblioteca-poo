### 📚 Sistema de Gestão de Biblioteca
📌 Descrição

Este projeto foi desenvolvido como atividade prática de Programação Orientada a Objetos (POO).

O sistema permite cadastrar itens de uma biblioteca, realizar empréstimos e devoluções, utilizando conceitos como:

Encapsulamento

Herança

Polimorfismo

Organização em múltiplos arquivos

Versionamento com Git e GitHub

### 🚀 Funcionalidades

✔ Cadastro de Livro
✔ Cadastro de Revista
✔ Listagem de itens cadastrados
✔ Empréstimo de item por código
✔ Devolução de item por código
✔ Controle de disponibilidade
✔ Menu interativo no terminal

### ▶️ Como Executar

Clone o repositório:

git clone https://github.com/rayssa955/biblioteca-poo.git

Acesse a pasta do projeto:

cd biblioteca-poo

Execute o sistema:

python main.py

ou

python3 main.py
### 💡 Exemplos de Uso

Ao executar o programa, será exibido um menu:

1. Cadastrar Livro
2. Cadastrar Revista
3. Listar Itens
4. Emprestar Item
5. Devolver Item
6. Sair

O usuário pode cadastrar itens e gerenciar os empréstimos diretamente pelo terminal.

### 🧠 Conceitos Aplicados
